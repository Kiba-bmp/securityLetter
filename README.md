# Security Letter

Учебный браузерный тренажёр распознавания подозрительных писем для сотрудников малого бизнеса. Проект команды 50, тема KIB-51.

## Как запустить

### Через локальный сервер

Для этого способа нужен Python 3. Проверить его наличие можно командой `python3 --version`.

1. Откройте Терминал и перейдите в папку проекта:

   ```bash
   cd ~/dev/pismo-ok
   ```

   Если проект лежит в другом месте, подставьте путь к папке, в которой находятся `README.md` и `dist`.

2. Запустите сервер на порту 8000:

   ```bash
   python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
   ```

3. Оставьте Терминал открытым и перейдите в браузере по адресу [http://127.0.0.1:8000/](http://127.0.0.1:8000/). Чтобы остановить сервер, нажмите `Ctrl+C` в Терминале.

Если порт 8000 занят, замените в команде `8000` на `8001` и откройте [http://127.0.0.1:8001/](http://127.0.0.1:8001/). Сервер доступен только на компьютере, на котором запущен.

### Без сервера

Откройте файл `dist/index.html` двойным щелчком. Для тренировки не нужны установка зависимостей, регистрация или ключ API.

## Как показать прототип

1. Прочитайте учебное письмо и отметьте подозрительные признаки. Если их нет, выберите соответствующий вариант.
2. Нажмите «Проверить ответ». Лишние отметки и пропущенные верные варианты подсветятся красным. Под письмом появятся объяснения.
3. Пройдите остальные карточки, откройте итог и повторите тренировку.

Баллы начисляются за карточки, в которых выбран полный набор правильных вариантов. Ответы существуют только во время текущей тренировки.

## Проблема и актуальность

Руководителю или HR-менеджеру небольшой компании нужен простой способ потренировать сотрудников распознавать подозрительные признаки рабочей почты. Источники и факты добавляет аналитик.

## Модель угроз и тестирование

В карточках используются вымышленные ситуации. Приложение не отправляет письма, не принимает пользовательские письма и не собирает персональные данные. Модель угроз и результаты финальной проверки добавляет Security/QA.

## ИИ и ограничения

При подготовке первого прототипа использован Codex. В интерфейсе зарезервировано отключённое поле для ключа будущего сервиса. Текущая версия пока работает на трёх готовых карточках и не делает запросов к ИИ.
